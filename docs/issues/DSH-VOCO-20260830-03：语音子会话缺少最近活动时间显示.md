# DSH-VOCO-20260830-03：语音子会话缺少最近活动时间显示

## 问题信息
- 发现日期：2026-08-30
- 发现会话或复现方式：语音父会话展开 Agent 子会话后，子行只有名称和状态点，没有主会话同样的相对时间
- 相关模块或代码：`packages/ui-voice/src/client/VoiceSessionMarkers.tsx`、`packages/ui-voice/src/client/VoiceNodeViews.tsx`、`packages/ui-voice/src/client/voice-history.ts`
- 状态：处理中
- 验证情况：自动化回归测试已通过，待真实侧栏验收

## 问题描述
语音父会话下的 Agent 子会话应显示与普通会话行一致的最近活动时间，便于判断任务新旧和排序语义。

## 证据与复现
宿主 workspace 主会话行使用 `SessionListEntry.updatedAt`。宿主类型注释明确该字段是“epoch ms of the session's last activity”，不是首次消息时间。

当前宿主版本的 `SubagentListEntry` 仅提供 `id`、`activity`、`mode`、`label` 等字段，没有 `updatedAt`。子会话通常也从顶层 `sessions.ids` 移除，不能依赖顶层列表补齐时间。

## 影响
展开的子任务无法直观看出最近活动时间；若插件自行使用目录刷新时间，会把刷新时刻误报为会话活动时间。

## 原因判断
问题来自宿主子会话目录接口与主会话列表摘要的字段不对称，而不是相对时间格式本身。宿主的时间规则是按 `updatedAt` 与当前时间的差值分桶：小于 1 分钟、分钟、小时、天、月、年。

## 解决方案
1. 子目录条目未来提供 `updatedAt` 时，优先使用该宿主字段。
2. 若已存在 child summary，则使用其正数 `updatedAt`。
3. 兼容当前宿主版本，在语音父会话中记录每个委派任务最新的持久事件时间，作为没有宿主 child 时间字段时的回退；不使用目录刷新时间。
4. 子行复用宿主相同的时间分桶和紧凑显示规则，并每分钟刷新相对文本。

## 处理记录
- 2026-08-30：核对宿主 workspace 与 runtime 类型，确认主会话时间语义为最近活动时间，子目录当前没有对应字段。
- 2026-08-30：为委派任务状态增加最后事件时间；扩展 `VoiceHistoryStore` 记录 child activity；子行增加时间列和宿主兼容分桶格式。
- 2026-08-30：新增 child `updatedAt` 显示回归测试与当前宿主回退路径测试；类型检查、126 项全量测试和生产构建均通过。
- 2026-08-30：根据真实截图修正中文兼容格式，统一使用“36分钟”而不是“35分钟前”；新增中文格式回归测试。

## 后续低优先级优化
- 宿主 `SubagentListEntry` 增加正式的 `updatedAt` 字段后，移除或降低本地任务事件时间回退的优先级。
- 若宿主开放统一的 `timeLabel` 导出，可直接复用其本地化函数，避免插件保留兼容格式化器。
