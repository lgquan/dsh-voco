# DSH-VOCO-20260830-06：子会话输入框缺少模型选择器

## 问题信息
- 发现日期：2026-08-30
- 发现方式：用户截图反馈；打开语音委派 child 后，底部输入框只有权限模式选择，没有主会话同款模型选择项
- 相关模块或代码：`packages/ui-voice/src/client/index.ts`、`packages/voice-assistant/src/index.ts`、官方 `@deepseek-ai/dsh-client-ui-model-selection@0.1.1-rc.2`
- 状态：已解决
- 验证情况：自动化检查已通过；本地 Web 页面刷新后真实语音子会话显示当前模型，展开官方菜单可见 DeepSeek 与 TeamoRouter 全部目录，并成功切换到 `DeepSeek-V4-Pro` / `High`

## 问题描述
子会话可以继续输入消息，但输入框没有主会话中的模型选择器，无法在该 child 内查看或切换 provider、model 和 reasoning effort。

## 证据与复现
用户提供的页面截图显示，当前 child 的输入框底部有 `Workspace Write` 权限选择，但没有模型名称及下拉箭头。主会话输入框使用同一 `conversation.input.model` seat 时可以显示模型选择器。

检查 DeepSeek Harness 官方实现 `@deepseek-ai/dsh-client-ui-model-selection@0.1.1-rc.2` 后确认：

- 官方包负责主会话的 `ModelDirectory`、`ModelSelect`、`conversation.input.model` seat 和 `/model` 命令。
- `ModelDirectoryResolver`、composer seat 及 `/model` 命令均通过 `sessions.subagentAddress(...)` 隐藏 addressed child。
- 宿主后端的 `session.models` 与 `session.selectModel` RPC 在该版本会拒绝 `origin: 'subagent'` child，返回 `agent-busy`；冷启动 child 还可能尚未恢复为 live Agent。

## 影响
进入委派 child 后，用户只能沿用创建时的模型；需要为当前任务切换模型或 reasoning effort 时必须离开 child，操作不连续。

## 原因判断
这是 DeepSeek Harness 官方模型选择包的显式产品限制，不是 voice UI 自己漏渲染。该版本将所有 addressed subagent 视为不可独立选择模型的会话，因此即使 `conversation.input.model` seat 已存在，也会返回不可用并隐藏触发器。

## 解决方案
继续使用 DeepSeek Harness 官方模型选择实现，不新增自定义模型菜单或重复模型目录。只在 `dsh-voco` 插件中做兼容适配：

- `packages/ui-voice/src/client/index.ts` 临时将语音 child 的 UI 地址判定交给官方模型选择器，使其复用主会话同款按钮、目录和菜单。
- `packages/voice-assistant/src/index.ts` 在插件 Host 层包装官方 `session.models`/`session.selectModel` RPC：模型目录沿用父会话官方目录，选择结果绑定到 child 自己的 Agent selection；冷启动 child 按现有语音恢复路径懒恢复。
- 官方 Harness 主体、底层源码、`@deepseek-ai/dsh-client-ui-model-selection` 源码和 pnpm patch 均保持原样。

## 处理记录
- 2026-08-30：定位到官方包 `@deepseek-ai/dsh-client-ui-model-selection@0.1.1-rc.2`；确认其源码中有三处 addressed-subagent 限制，且宿主后端模型 RPC 可服务 child。
- 2026-08-30：撤销并删除官方模型选择包 patch，恢复 `packages/voice-app/package.json`、`pnpm-workspace.yaml` 和 `pnpm-lock.yaml` 的原始依赖配置。
- 2026-08-30：在 `dsh-voco` 客户端插件中增加 child UI 兼容 effect；保留官方模型选择 UI，不复制组件。
- 2026-08-30：在 `dsh-voco` Host 插件中接管官方模型 RPC，补充持久化 child 的懒恢复和 child-scoped model selection。
- 2026-08-30：`pnpm typecheck`、`pnpm build`、`pnpm test` 全部通过（132 tests）；真实 RPC `session.models` 返回 DeepSeek 与 TeamoRouter 目录，`session.selectModel` 返回成功。
